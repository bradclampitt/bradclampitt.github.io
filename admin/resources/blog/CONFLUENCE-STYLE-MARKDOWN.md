# Confluence-Style Markdown Features

Your blog system now supports Confluence-style markdown elements that enhance content presentation and readability.

## 📋 **Info Boxes and Callouts**

### Info Box
```markdown
^ info
This is an informational callout that provides helpful context
or additional details about the topic being discussed.
```

### Warning Box
```markdown
! warning
This is a warning callout that highlights important cautions
or potential issues users should be aware of.
```

### Success Box
```markdown
✓ success
This is a success callout that indicates completed tasks,
achievements, or positive outcomes.
```

### Error Box
```markdown
✗ error
This is an error callout that explains what went wrong
or things to avoid.
```

### Tip Box
```markdown
💡 tip
This is a tip callout that provides helpful hints,
shortcuts, or best practices.
```

**Rendered Output:** Each box will appear as a styled container with:
- Colored left border and background
- Appropriate icon (info, warning, check, X, lightbulb)
- Professional styling with Tailwind CSS

## 🖼️ **Enhanced Image Handling**

### Standard Images
```markdown
![Image description](path/to/image.jpg)
```

### Centered Images
```markdown
![Image description](path/to/image.jpg){: .center}
```
